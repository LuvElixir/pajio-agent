# 0002 · 客户端全部原生实现

2026-10-12 · 已决定

## 决定

App 和桌面端的产品界面都用原生实现，不再把网页界面嵌进 WebView。

- **App**：React Native / Expo，渲染系统原生控件。聊天已于 2026-10-12 从 WebView 换成原生实现。
- **桌面**：现有 Tauri 外壳本质上是在系统 WebView 里加载网页端，需要替换。原生方案（SwiftUI，或复用 App 代码的 react-native-macos）尚未选定。
- **网页端**：不再追求与 App 体验对齐，定位另行决定。

## 例外

内容可以使用 WebView，界面外壳不可以：Agent 生成的 HTML 产物、远程画面查看器可以继续使用 WebView。

## 理由

WebView 搬到手机上，键盘、手势、返回、后台恢复的手感都明显差于原生，而且同一产品维护三套界面成本过高。
