# 0003 · 每位用户独立 VM，设备能力属于核心

2026-10-12 · 已决定

## 决定

- 保持每位用户一台硬件虚拟化隔离的独立 VM，不改为共享多租户运行时。
- 专属 Linux 云电脑、Android 云手机和私密远程接管属于底座核心能力，继续投入。
- 日历、任务、笔记、收藏、简报、健康记录、飞书等生活工具全部作为扩展。

## 讨论过、未采用

共享多租户运行时（租户 ID 加数据库行级隔离）单用户成本更低。没有采用，是因为"Agent 能真正替用户操作电脑和手机"是这条路线的核心差异，需要强隔离来承载。

## 影响

- 内测规模受主机容量约束；扩大范围前需要验证容量、48 小时稳定性和费用。
- 自助供应、自动空闲关机与按时计费尚未实现，内测期间由运营人员手动供应。
