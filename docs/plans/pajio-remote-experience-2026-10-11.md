# Pajio App 远程接管界面

## 目标与布局

云手机和 Linux 云电脑共用一套接管界面。优先展示远程画面，让用户始终能辨认当前由谁操作。

1. **查看设备**：顶部为返回、设备名称、控制状态和“完成”。连接后默认仅查看；Pajio 已暂停。
2. **操作设备**：底部一条工具栏，包含“查看 / 操作”、键盘、设备工具。选中态使用产品已有 selection 色板和边框。主界面不重复展示 Android 三键导航。
3. **输入与快捷键**：按需打开产品统一底部面板。手机提供返回、主页、最近任务；电脑提供 Tab、Esc、方向键和滚动按钮。能力未就绪时说明原因，不伪造成功。
4. **完成接管**：顶部“完成”打开会话面板，分为“交还 Pajio”和“断开连接”。交还仍需确认离开私密页面、允许助手继续，并收到设备回执。断开保持暂停。

改版前的主要问题：常驻说明加上四排不同含义的大按钮压缩画面；Android 导航与会话操作混排；开始操作、停止操作、交还和退出缺乏层级。用户提供的截图与本次真机截图均可复现。

## 实现边界

- 复用现有 Sheet、IconButton、TactilePressable 和主题色；键盘及工具面板不重新创建 WebRTC 会话。
- 保留原有会话代次、设备确认、过期、后台暂停、禁止重放和输入能力检查。
- 新增电脑滚动桥接，数值必须有限，限制在 ±1000；只在明确操作模式、能力开启和新画面有效时发送。
- 输入内容隐藏显示、发送后清空、关闭面板后清空，不写日志。
- 返回仍关闭画面并保持设备暂停。交还成功与仅关闭画面具有不同反馈。

## 验证

2026-10-11：TypeScript 检查与修改文件 ESLint 通过；远控回归 30 项通过，覆盖会话隔离、输入能力、陈旧画面、后台、交还和滚动边界。

已将签名 Release 0.2.0（6）安装到用户的 Luvloving iPhone，保留原账号。真机已确认：

- 云手机查看和操作选中状态；新布局放大画面，只常驻一条工具栏。
- 手机快捷键中的主页实际生效；打开/关闭工具和键盘面板没有重建画面连接。
- 私密输入发送测试文字 `QA` 后，远端输入框显示同样文字；没有提交搜索。发送后和重新打开面板时内容已清空。
- “完成”面板的交还路径，经两项确认后显示“设备已确认交还，Pajio 可以继续操作”。
- 会话过期保持设备暂停，重新连接后回到仅查看模式。

Linux 本次真机验收尚未完成：Device Hub 镜像的设备列表滚动会直接跳过中部卡片，已请求用户在手机上打开专属 Linux 入口。代码与云手机共用查看/操作、完成和输入布局，电脑滚动桥接已过回归，但不据此宣称 Linux 真机通过。
