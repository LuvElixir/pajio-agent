# Pajio App 远程接管界面

## 目标与布局

云手机和 Linux 云电脑共用一套接管界面。优先展示远程画面，让用户始终能辨认当前由谁操作。

1. **查看设备**：顶部为返回、设备名称、控制状态和“完成”。连接后默认仅查看；Pajio 已暂停。
2. **操作设备**：底部一条工具栏，包含“查看 / 操作”、键盘、设备工具。选中态使用产品已有 selection 色板和边框。主界面不重复展示 Android 三键导航。
3. **输入与快捷键**：按需打开产品统一底部面板。手机提供返回、主页、最近任务；电脑提供 Tab、Esc、方向键和滚动按钮。能力未就绪时说明原因，不伪造成功。
4. **完成接管**：顶部“完成”打开会话面板，分为“交还 Pajio”和“断开连接”。交还仍需确认离开私密页面、允许助手继续，并收到设备回执。断开保持暂停。

改版前的主要问题：常驻说明加上四排不同含义的大按钮压缩画面；Android 导航与会话操作混排；开始操作、停止操作、交还和退出缺乏层级。用户提供的截图与本次真机截图均可复现。

## 实现边界

- 复用现有 Sheet、IconButton、TactilePressable 和主题色；键盘及工具面板不重新创建 WebRTC 会话。
- 保留原有会话代次、设备确认、过期、后台暂停、禁止重放和输入能力检查。
- 新增电脑滚动桥接，数值必须有限，限制在 ±1000；只在明确操作模式、能力开启和新画面有效时发送。
- 输入内容隐藏显示、发送后清空、关闭面板后清空，不写日志。
- 返回仍关闭画面并保持设备暂停。交还成功与仅关闭画面具有不同反馈。

## 远控手势增补（2026-10-11）

参考官方 [AnyDesk iOS 输入方式与会话菜单](https://support.anydesk.com/anydesk-for-ios-ipados-tvos) 和 [网易 UU 远程的 App Store 产品说明](https://apps.apple.com/cn/app/id1642306791)。采用观看和操作分开、触控板与直接触控可切换、键盘与特殊键按需展开的成熟模式。UU 官网本次未能访问，因此不把第三方仿站中的手势说明当作官方依据。

### 真机复现与修复范围

- 在 Luvloving 的 Release 0.2.0（6）中，进入 Linux“操作”后，从桌面内部向上拖入留白，立即断开，并错误提示“设备画面尺寸改变”。源代码把 `locate=null`（离开图片边界）与真实远端尺寸变化混为同一错误。
- 旧版第二根手指直接触发 `gesture_interrupted`；电脑手指按下便发送鼠标按下，无法在缩放前撤销误触。
- 新版仅远端真实尺寸变化才结束该映射。拖出边缘时夹紧坐标，正常释放鼠标；手势被系统取消时也释放，不主动销毁正常连接。
- Linux 默认触控板：单指滑动移动光标，轻点点击，长按后拖动；可以切换直接触控。工具内提供左右键和滚动按钮。
- Android 保留单指轻点／滑动。两类设备都支持 1–4 倍本地缩放、双指平移、放大／缩小按钮和“适应”复位。查看模式下，放大后单指可平移画面。
- 双指从识别到所有手指离开均不发送远端触摸；已经按下的鼠标会先释放，防止粘住。
- 光标移动最多一个未确认请求，丢弃中间位置，不积压轨迹。点击、按下／释放保留有序传输；输入超时仍安全停止。
- 短暂静止画面中断先暂停输入、遮住旧帧，恢复后仅查看，不自动恢复操作、不重放旧输入；持续中断、未确认输入、按住鼠标时断帧继续安全结束连接。
- Linux 基础镜像补全官方 Ubuntu 软件包 `xfce4-terminal`、`thunar`、`mousepad`，当前用户专属 VM 同步补装；没有清除用户文件。
